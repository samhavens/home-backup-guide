# Home backup power guide

A mobile-friendly, large-print decision guide for Bob and Roberta.

Published at https://samhavens.github.io/home-backup-guide/

GitHub Pages serves the `docs/` directory from `main`. The site is static HTML, CSS, and JavaScript with no build step, analytics, or server dependencies. No form answers are collected. The text-size preference is stored locally in the browser.

`VERIFY.md` records the acceptance checks. `PRODUCT.md` and `DESIGN.md` describe the audience and presentation decisions. Costs are planning estimates, and assistance eligibility must be confirmed directly with the program.
